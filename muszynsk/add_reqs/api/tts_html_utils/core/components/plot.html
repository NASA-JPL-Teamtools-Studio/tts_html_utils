class tts_html_utils.core.components.plot.PlotBase(fig=None, title=None, template=None, class_name=None, extra_class_name=None, id=None, style=None, include_plotlyjs=False, full_html=False)

Bases: HtmlComponent

The base wrapper for embedding Plotly figures into the HTML document.

Concept: Plotly produces interactive, JavaScript-based charts. To put them in an HTML file, we need to convert the Python Figure object into a specific block of HTML/JS code.

Important Note on Performance: This component renders with include_plotlyjs=False. The global plotly.js library is automatically requested via the component’s js_includes and managed by the HtmlCompiler to ensure it is loaded once in the <head>.

Parameters:

  • fig (plotly.graph_objects.Figure, optional) – The existing Plotly figure to render. If None, creates a blank figure.

  • title (str, optional) – Sets the title of the plot layout.

  • template (str, optional) – The visual theme to use (e.g., ‘plotly_dark’, ‘seaborn’, ‘ggplot2’). Defaults to ‘seaborn’.

  • class_name (str, optional) – Primary CSS class for the container Div.

  • extra_class_name (str, optional) – Additional CSS classes.

  • id (str, optional) – Optional. A custom ID for this container. If not provided, a unique ID will be generated.

  • style (dict, optional) – Dictionary of inline CSS styles for the container Div.

add_trace(y, x=None, name=None, lines=False, markers=True, trace_kwargs=None, scatter_kwargs=None)

Adds a new data series (trace) to the plot.

Parameters:

  • y (list or array-like) – The Y-axis data points.

  • x (list or array-like, optional) – The X-axis data points.

  • name (str, optional) – The name of this series (appears in the legend).

  • lines (bool, default False) – If True, connects points with lines.

  • markers (bool, default True) – If True, draws a dot at each data point.

  • trace_kwargs (dict, optional) – A passthrough dictionary of arguments sent to self.fig.add_trace. Useful for advanced layout options like secondary_y=True.

  • scatter_kwargs (dict, optional) – A passthrough dictionary of arguments sent to go.Scatter. Useful for styling options like line_color, marker_size, etc.
