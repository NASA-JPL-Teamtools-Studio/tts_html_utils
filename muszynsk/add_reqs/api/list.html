class tts_html_utils.core.components.list.PowerList(children=None, class_name=None, extra_class_name=None, style=None, ordered=False)#

A smart builder for creating complex, nested lists without the headache.

The Problem: Creating nested HTML lists is very repetative. You have to remember to open a <ul>, add an <li>, open a new <ul> inside that <li> for the sub-items, and then close everything in the exact reverse order.

The Solution: PowerList works like a text editor’s outline mode. You simply add a line, and command it to “indent” (up_level) or “outdent” (down_level). It tracks where you are in the hierarchy and handles all the tag nesting for you automatically.

Parameters:

  • children (List, optional) – Initial list items to populate. (Usually better to use .line() after init).

  • class_name (str or list of str, optional) – CSS classes for the root list element.

  • extra_class_name (str or list of str, optional) – Additional CSS classes to append.

  • style (dict, optional) – Inline CSS styles for the root list element.

  • ordered (bool) – If True, renders as a numbered list (<ol>). If False, renders as bullets (<ul>). Defaults to False.

down_level()#

Outdents the list (returns to the parent level).

How it works: Moves the internal “cursor” back up to the parent list.

line(line, class_name=None, extra_class_name=None, style=None)#

Appends a new item to the current level of the list.

Parameters:

  • line (str or HtmlComponent) – The content of the item (text or another HtmlComponent).

  • class_name (str or list of str, optional) – CSS classes for this specific list item (<li>).

  • extra_class_name (str or list of str, optional) – Additional CSS classes to append.

  • style (dict, optional) – Inline CSS styles for this specific list item.

render()#

Converts the internal PowerList structure into standard HTML components (UL/OL and LI) and renders them to a string.

up_level(label=None, new_list=None, class_name=None, extra_class_name=None, style=None, ordered=None)#

Indents the list (creates a sub-list).

How it works: This creates a new list (container) and nests it inside the last item you added. The internal “cursor” moves to this new list, so subsequent .line() calls will appear as sub-items.

Parameters:

  • label (str or HtmlComponent, optional) – Optional text to place on the parent item before the sub-list starts.

  • new_list (UL or OL, optional) – If you have already built a UL or OL object, you can pass it here to insert it.

  • class_name (str or list of str, optional) – CSS classes for the new sub-list container.

  • extra_class_name (str or list of str, optional) – Additional CSS classes to append.

  • style (dict, optional) – Inline CSS styles for the new sub-list container.

  • ordered (bool, optional) – If True, the sub-list will be numbered. If False, bulleted. Defaults to the parent list’s type.
