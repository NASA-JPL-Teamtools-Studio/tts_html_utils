class tts_html_utils.core.components.misc.Link(text, href=None, new_tab=True, **kwargs)

Bases: HtmlComponentSimple

A hyperlink (Anchor tag).

Concept: The fundamental connector of the web. Links one page (or section) to another.

Alias: A

Parameters:

  • text (str) – The clickable text the user sees.

  • href (str, optional) – The destination URL. If None, defaults to the text (useful if pasting raw URLs).

  • new_tab (bool, optional) – If True, clicking the link opens a new browser tab (target=”_blank”). If False, it navigates the current tab. Defaults to True.

  • kwargs – Additional keyword arguments passed to the HtmlComponent constructor.

class tts_html_utils.core.components.misc.TtsFavicon

Bases: Script

Injects the Teamtools Studio logo into the browser tab.

How it works: Instead of requiring you to manage a physical .ico or .png file on the server, this class contains the base64-encoded image data of the logo. It uses a small JavaScript snippet to create the link tag dynamically and attach it to the document head.
