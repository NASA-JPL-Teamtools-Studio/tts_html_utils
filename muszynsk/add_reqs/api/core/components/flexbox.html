class tts_html_utils.core.components.flexbox.FlexContainer(children=None, direction='row', justify='flex-start', align='stretch', wrap='nowrap', gap=None, **kwargs)

Bases: HtmlComponentSimple

A flexible container that uses CSS Flexbox for layout.

Concept: The FlexContainer is a div with display:flex that allows for easy arrangement of child elements in rows or columns with precise control over sizing and spacing.

Parameters:

  • children (list or single HtmlComponent) – Child components to be arranged in the flex container.

  • direction (str, optional) – The flex-direction property. Options: ‘row’, ‘column’, ‘row-reverse’, ‘column-reverse’.

  • justify (str, optional) – The justify-content property. Options: ‘flex-start’, ‘flex-end’, ‘center’, ‘space-between’, ‘space-around’, ‘space-evenly’.

  • align (str, optional) – The align-items property. Options: ‘flex-start’, ‘flex-end’, ‘center’, ‘stretch’, ‘baseline’.

  • wrap (str, optional) – The flex-wrap property. Options: ‘nowrap’, ‘wrap’, ‘wrap-reverse’.

  • gap (str, optional) – The gap between flex items (e.g., ‘5px’, ‘1rem’).

  • kwargs – Additional keyword arguments passed to the parent Div.

class tts_html_utils.core.components.flexbox.FlexItem(children=None, width=None, height=None, grow=None, shrink=None, basis=None, align_self=None, **kwargs)

Bases: HtmlComponentSimple

A flex item that can be placed inside a FlexContainer.

Concept: FlexItems are divs with flex properties that control how they grow, shrink, and what their base size is within a FlexContainer.

Parameters:

  • children (list or single HtmlComponent) – Child components inside this flex item.

  • width (str, optional) – The width of the item (e.g., ‘50%’, ‘200px’, ‘auto’).

  • height (str, optional) – The height of the item (e.g., ‘100px’, ‘auto’).

  • grow (int, optional) – The flex-grow property (how much the item can grow). Default is 0 (no growing).

  • shrink (int, optional) – The flex-shrink property (how much the item can shrink). Default is 1 (can shrink).

  • basis (str, optional) – The flex-basis property (base size before growing/shrinking). Default is ‘auto’.

  • align_self (str, optional) – Override the container’s align-items for this specific item.

  • kwargs – Additional keyword arguments passed to the parent Div.
