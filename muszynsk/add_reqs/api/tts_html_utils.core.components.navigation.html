tts_html_utils.core.components.navigation

class tts_html_utils.core.components.navigation.Navbar(mapping, new_tab=False, **kwargs)

Bases: PowerList

Simple class to streamline creation of a navbar, which is essentially an unordered list of links.

Nothing special now, but eventually this will be part of stock templates and will include out of the box CSS

Parameters:

  • mapping – Dictionary where keys are labels and values are URLs

  • new_tab (bool) – Should links open to a new tab or in the current one?

  • kwargs – Additional keyword arguments passed to the HtmlComponent constructor.

add_items(mapping, new_tab=False)

Add an item to an existing Navbar. This is equivalent to including the item in the mapping parameter of __init__()
