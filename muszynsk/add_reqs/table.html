class tts_html_utils.core.components.table.Header(column_names, class_name=None, extra_class_name=None, style={}, add_filters=False, include_sorting=False)#

The Table Head section (<thead>).

Concept: A special row group reserved for column titles. Browsers and printers treat this differently than the body (e.g., repeating the header on every page of a printout).

Note: While you can use this class manually, PowerTable creates this automatically via the add_header method.

Parameters:

  • column_names (List[str]) – A list of strings to be used as column titles.

  • class_name (str, optional) – CSS classes for the header row.

  • extra_class_name (str, optional) – Additional CSS classes.

  • style (dict, optional) – Inline CSS styles.

  • add_filters (bool) – If True, injects <input> boxes for column filtering. Used internally by PowerTable when filtering is enabled.

class tts_html_utils.core.components.table.PowerTable(column_fields=None, row_data=None, class_name=None, extra_class_name=None, id=None, style={'text-align': 'left'}, row_styles=None, cell_classes=None, cell_styles=None, add_filters=None, add_sorting=None)#

The “Swiss Army Knife” of tables.

Concept: Building tables tag-by-tag (<table>, <thead>, <tbody>, <tr>, <td>…) is tedious. PowerTable allows you to pass a list of Python dictionaries or tuples, and it automatically constructs the full HTML structure.

Advanced Features: It supports “Expandable Rows” (accordion details), sorting, and filtering via pre-packaged JavaScript libraries included in this module.

Parameters:

  • column_fields (List[str], optional) – A list of keys (e.g. [‘name’, ‘age’]) to extract from row_data dictionaries. If None, it infers them from the keys of the first row.

  • row_data (List[dict] or List[tuple], optional) – The actual data to display. Format 1 (Simple): A list of dicts: [{‘name’: ‘Bob’}, {‘name’: ‘Alice’}]. Format 2 (Expandable): A list of tuples: [(primary_data_dict, hidden_details_html)]. If the second element of the tuple is not None, a hidden detail row is created that expands when the user clicks the main row.

  • class_name (str or list, optional) – CSS class for the table. Defaults to [‘power-table’, ‘alternating’, ‘sticky-header’].

  • extra_class_name (str or list, optional) – Additional CSS classes.

  • id (str, optional) – Unique ID. If None, a UUID is generated automatically (required for JS features).

  • style (dict, optional) – Inline CSS styles. Defaults to {‘text-align’: ‘left’, ‘border’: ‘2px black solid’}.

  • row_styles (List[dict], optional) – A list of style dicts, one for each row in row_data.

  • cell_classes (List, optional) – A list of class strings/lists, one for each row.

  • cell_styles (List, optional) – A list of style dicts, one for each row.

  • add_filters (str, optional) – Enables search inputs in the header. Options: ‘local’, ‘django’, or None.

  • add_sorting (str, optional) – Enables column sorting. Options: ‘local’, ‘django’, or None.

class tts_html_utils.core.components.table.Row(children=None, class_name=None, extra_class_name=None, tag=None, id=None, style=None, apply_cells=True, cell_styles=None)#

A table row (<tr>).

Concept: A horizontal container that holds Cell objects. HTML tables are row-oriented; you cannot define columns directly, only rows of cells.

Parameters:

  • children (List, optional) – The contents of the row. Can be Cell objects, strings, or numbers.

  • class_name (str or list of str, optional) – CSS classes for the row.

  • extra_class_name (str or list of str, optional) – Additional CSS classes to append.

  • tag (str, optional) – The HTML tag. Defaults to ‘tr’. (Rarely needs changing).

  • id (str, optional) – HTML id attribute.

  • style (dict, optional) – Inline CSS styles.

  • apply_cells (bool) – If True, automatically wraps plain strings/numbers in Cell objects. If False, assumes children are already valid HTML components. Defaults to True.

  • cell_styles (list, optional) – A list of style dictionaries to apply to the generated cells. Must match the length of children.

class tts_html_utils.core.components.table.Superheader(text, collapsible=False, default_closed=False, class_name=None, extra_class_name=None, style={})#

A secondary header row that sits above the main column headers.

Concept: Often used for a table title or to group multiple columns under a single category. This element spans all columns (colspan=100%) by default.

Parameters:

  • text (str) – The text to display in the superheader.

  • collapsible (bool) – Enables accordion-style collapsing of the table body.

  • default_closed (bool) – If collapsible is True, this sets the initial state to closed.

  • class_name (str, optional) – CSS classes.

  • extra_class_name (str, optional) – Additional CSS classes.

  • style (dict, optional) – Inline CSS styles.
